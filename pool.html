第一次使用：从来源到 S5

① 获取候选

VPN Gate 已内置。也可点击下方公共列表按钮，或导入供应商提供的代理列表、OpenVPN 配置。

② 建立出口

首次选“不限地区”，数量建议 1–3。候选只代表来源提供了地址，连接检测成功才算可用。

③ 识别与提取

连接后查询真实出口国家与运营商。绿色“可用”的出口可提取 S5；连接地址是你的 VPS，访问网站时显示的 IP 是真实出口。

④ 自动维护

确认单个出口可用后再开启自动补充。刷新来源不会自动建立全部候选，也不会把候选数量变成在线数量。

“待识别”和“住宅未验证”分别是什么意思？

国家：普通 IP:端口列表没有地区资料，连接前显示“待连接识别”；成功连接后查询真实出口国家。住宅属性：普通国家查询不能判断住宅或机房，未配置专门的检测接口时显示“住宅未验证”。协议：表示这个入口支持 TCP 还是 TCP/UDP，与国家和住宅属性无关。

手动填写国家码只是来源标签。不要把混合国家的公共列表统一写成 JP 或 US，否则会影响连接前的地区筛选。

常见问题与排查

添加来源后为什么在线数量还是 0？

来源只是候选池。点击“批量建立出口”，或启用自动补充。混合地区列表先选“不限地区”；新来源暂时没有国家信息时，选特定国家可能找不到候选。

来源添加失败或出口一直失败

确认 VPS 能访问订阅地址，订阅返回的是纯文本内容而不是登录页。已有代理检查账号密码、上游端口和白名单；OpenVPN 检查配置有效期、证书及 TUN 支持。点出口“日志”查看原因，公共节点失效可换其他来源。

S5 提取出来后如何使用？

在支持 SOCKS5 的客户端填写 VPS IP、面板显示的端口、用户名和密码。S5 链接可直接导入支持它的客户端。若面板显示可用但客户端连不上，检查 VPS 防火墙和服务商安全组是否放行这个 TCP 端口。SOCKS5 用户名密码本身不提供 TLS 加密。

提取令牌有什么用？

用于其他程序定时读取在线出口，不能管理或删除节点。生成新令牌会使旧令牌立即失效。弹窗会给出完整请求地址、请求头及筛选参数；不要把令牌放在公开网页中。

升级后如何保留配置？

下载本仓库 Releases 中的完整安装包，解压后执行 sudo bash install.sh。安装程序沿用 /var/lib/fanout-integrated 中的配置与凭据。升级前可先备份该目录，升级后刷新浏览器并重新识别在线出口。

OpenVPN 出口支持 TCP / UDP；已有代理转换支持 TCP。连接失败时不回退母机直连。节点列表中的国家由来源提供，实际属性以检测结果为准。
